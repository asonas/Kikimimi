# Kikimimi アイコンの方針

2026-11-10追記: 片耳が垂れる耳の意匠と生成り・墨色の配色を採用した。実装は `App/Icon/KikimimiA3/Kikimimi.icon`。`mise run icon`で編集し、Xcodeがビルド時に各サイズと旧OS向け画像を生成する。以下の仮アイコンとSVG書き出しの説明は選定時点の記録である。

アイコンを仕上げるときの前提資料。アプリが何をするか、使う人はどんな場面にいるか、アイコンで何を伝えたいかをまとめる。今のアイコンは方向を決めるための仮の版で、ここから作り直す前提である（Linear ASO-110）。

## アプリの概要

Kikimimi は、自分が受けるオンライン面接を録音して書き起こす macOS アプリである。Meet や Zoom に録音用のボットを参加させず、手元の Mac だけで動く。

- 相手の声と自分の声を、別々のトラックとして録音する。相手の声は会議アプリ（Chrome や Zoom）の音だけを画面収録の仕組みで取り、自分の声はマイクから取る。ほかのアプリの音や通知音は入らない。
- 録音のあと、Mac の中で書き起こす（Whisper large-v3-turbo）。音声も文字も外に送らない。
- 書き起こしは発話ごとに「自分」「相手」と時刻を付けて並べ、Markdown でも保存する。
- 録音中にアプリが落ちても、次の起動で録音を復元する。
- 録音の開始、停止、状態の確認は、メニューバーとメインウィンドウのどちらからでもできる。

### これから入る予定の機能

Linear の interview-recorder プロジェクトにある Issue。アイコンが将来の機能と食い違わないように挙げておく。

- Google カレンダーと連携し、予定から録音を始める。保存名に予定の名前を使う（ASO-111〜113）。
- ChatGPT（Sign in with ChatGPT または API キー）で面接の内容をまとめる（ASO-114、115）。まとめるときだけ、利用者の操作で外に送る。
- 書き起こしの保存先を選ぶ。たとえば Obsidian の vault（ASO-116）。

## 使う人と場面

- 転職活動中に、自分の面接を振り返りたい人。最初の利用者は作者本人である。
- 面接の直前と最中に使う。緊張している時間帯なので、アイコンは落ち着いて見え、録音中かどうかが一目で分かる必要がある。
- 面接のあとで、何を聞かれ、どう答えたかを読み返す。アプリを開く目的は、録音そのものより振り返りにある。

## 名前の意味

「聞き耳（ききみみ）」から取った。相手の言葉を聞き逃さない、という意味を込めている。

ただし「聞き耳を立てる」には「盗み聞き」の含みもある。このアプリは自分の会話を自分のために残す道具なので、盗聴や監視を思わせる絵柄は避ける。

## アイコンで伝えたいこと

優先度の高い順に挙げる。

1. 2 つの声を分けて残すこと。自分と相手が別トラックになっているのが、このアプリのいちばんの特徴である。
2. よく聞くこと。名前の「聞き耳」につながる要素。
3. 手元で完結し、安心して使えること。外に送らない、ボットを入れない、という控えめさ。
4. 録音のあとに読み返すこと。書き起こしや振り返りにつながる要素。

全部を 1 枚に詰め込む必要はない。1 と 2 を軸にして、3 は色や質感の落ち着きで表すのがよいと考えている。

## 避けたいもの

- 盗聴、監視、隠しマイクを思わせる絵柄（耳に当てたコップ、虫、目、鍵穴など）。
- 赤い録音ボタンを主役にすること。録音中の表示はメニューバーのアイコンが担っている。アプリのアイコンまで赤くすると、常に録音中のように見える。
- 汎用の録音アプリ（ボイスメモ、Audio Hijack など）と見分けがつかない、マイク 1 本だけの絵柄。

## 今の仮アイコン（案 B）

`App/Icon/AppIcon.svg`。暗い背景に、橙と青緑の波形を 2 段に重ねたもの。上の段が相手、下の段が自分を表す。

3 つの案から利用者がこれを選んだ。ほかの 2 案は次のとおり。

- A: 紺の背景に、白い線で描いた耳と音波。ラフでは耳が電球に見えた。
- C: 生成り色の背景に、うさぎの耳を 2 本。左右の耳の内側を別の色にして、2 つのトラックに見立てた。

案 B の課題は次のとおり。

- 波形の棒を並べただけなので、汎用の音声アプリと見分けにくい。「聞き耳」の要素がない。
- 16px や 32px では棒が細すぎてつぶれる。
- 角丸の板、陰影、質感が平板で、macOS の他のアイコンと並べると浮く。

## 作るうえでの制約

- 対象は macOS 14 以降。macOS 26 以降は Liquid Glass の見た目になり、Xcode の Icon Composer で作る `.icon` 形式が使える。古い OS 向けの画像も必要になる。
- 今の仕組み: `mise run icon` が `App/Icon/AppIcon.svg` から `App/Assets.xcassets/AppIcon.appiconset` の 10 枚（16〜512 の 1x と 2x）を書き出す。`.icon` 形式に移る場合は、この仕組みを置き換える。
- 原画は 1024 角で、Apple のグリッドに合わせて 824 角、角丸 185 の板を描いている。
- メニューバーのアイコンは別にあり、SF Symbols で状態を示している。待機中は `mic`、録音中は赤の `record.circle.fill`、書き起こし中は `text.bubble`、要対応はオレンジの `mic.badge.exclamationmark` である。アプリのアイコンの主題をメニューバー用の単色テンプレート画像にも落とせるなら、揃えると印象が強まる。
- 作者の別のアプリに YoruMimizuku（夜みみずく）がある。名前の付け方（和語のローマ字）が同じなので、並べたときに同じ作者のアプリと分かると嬉しい。必須ではない。

## 方向の案

ブラッシュアップの出発点として挙げる。

- 2 本の波形を、耳の輪郭の中に収める。または 2 本の波形で耳の形を作る。
- 案 C のうさぎの耳を洗練させ、左右の耳を 2 つのトラックの色にする。親しみやすさと「聞き耳」が両立する。盗み聞きの印象は弱い。
- 吹き出しを 2 つ重ね、片方の中に波形、もう片方の中に文字の線を入れる。2 人の会話と書き起こしを表す。「聞き耳」の要素は弱い。
